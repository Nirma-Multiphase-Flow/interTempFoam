# interTempFoam

A non-isothermal, sharp-interface two-phase VOF solver with phase change for **OpenFOAM v2412**
(openfoam.com), derived from `interFoam` / `interIsoFoam`. It adds an energy equation and a
sharp-interface evaporation/condensation model on top of geometric (isoAdvector + PLIC) VOF.

> **Status: research code.** Validated on the 1D Stefan problem and the axisymmetric d²-law droplet
> (see [Validation](#validation)); other cases in `validation/` are generators, with results not
> summarised here. Check a case against a reference before relying on it.

## Features

- Geometric VOF with `isoAdvection` and PLIC reconstruction (`plicRDF`); alpha stays bounded and
  volume is conserved to about 1e-11 (relative) without phase change.
- Phase change through the **total interface velocity** `u_t = u + u_PC` (Gada & Sharma 2009, Eq. 13;
  Shaikh et al. 2016, Eq. 8) with the interface normal taken from the reconstructed distance function
  (RDF), not from `grad(alpha)`.
- `HardtWondra` sharp-interface model: ghost-fluid Tsat condition on the temperature, mass flux from
  pure-cell probes (Malan et al. 2021), shifted dilatation (Hardt & Wondra 2008).
- Interface curvature from the PLIC signed distance (`interfaceCurvatureITF`): `gradAlpha`, `RDF`,
  `heightFunction` or `constant`.
- Builds against the stock v2412 libraries; no extra library to compile.

## Formulation (as implemented)

**Interface advection** (`alphaEqn.H`, `alphaPCVelocity.H`). With `phiT = phi + phiPC`,
`u_PC = (mdot''/rho1) n`, `n = grad(psi)/|grad(psi)|` (`psi` = `psiRDF`, positive in phase 1):

```
d(alpha1)/dt + div(alpha1 phiT) = alpha1 div(phiPC)
```

`mdot'' = mdot'''/aInterface` is the mass flux per interface area (PLIC area density), `mdot'''` is
`-rho1 alpha1Gen`. The right-hand side is passed to `advect()` as `Su`. In a pure cell it cancels the
flux term exactly, so volume changes only at the interface. `1/rho1` is the consistent speed because the
dilatation is shifted off the interface (below), which leaves the liquid velocity at the interface.
`rhoPhi` and `rhoCpPhi` remove the phase-change part of the flux so momentum and enthalpy see the bulk
flux. `phaseChangeAdvection source;` selects the older explicit-source path (`alphaSuSp.H`) for comparison.

**Continuity** (`pEqn.H`): `div(U) = PCV`, with PCV the Helmholtz-smoothed `mdot'''` moved into the
non-interface cells of the lighter phase and scaled by `(1/rho2 - 1/rho1)`.

**Momentum** (`UEqn.H`): standard `p_rgh` formulation with CSF surface tension `sigma kappa snGrad(alpha1)`.

**Energy** (`TEqn.H`): `ddt(rhoCp T) + div(rhoCpPhi, T) - laplacian(kappaf, T) + TSource = 0`. In
`HardtWondra`, conduction across interface-crossing faces is removed and replaced by an implicit
Dirichlet term `a (T - Tsat)` on each side (Gibou et al. 2002); the heat removed equals `L * mdot`.

**Time step:** the phase-change interface speed `|mdot''|/rho1` limits the step; the capillary limit is
reported as a warning for fixed time steps. Local time stepping is not supported.

## Build

```bash
source /usr/lib/openfoam/openfoam2412/etc/bashrc     # or your v2412 environment
cd applications/solvers/multiphase/interTempFoam/interTempFoam
wmake
```

The executable goes to `$FOAM_USER_APPBIN`. Check the build output for warnings; the ones coming from
OpenFOAM's own headers (`-Woverloaded-virtual`) are expected.

## Case set-up

A minimal working set is generated by `validation/V34_stefan1d/gen.py` (1D) and
`validation/V6_d2law_axi/gen.py` (axisymmetric wedge).

`constant/transportProperties` (two phases, each with `cp` and `Pr`; conductivities come from
`phaseChangeProperties`):

```
phases (water vapour);
water  { transportModel Newtonian; nu 2.9e-7; rho 958; cp 4216; Pr 1.75; }
vapour { transportModel Newtonian; nu 2.0e-5; rho 0.6; cp 2080; Pr 1.0;  }
sigma           0.059;
curvatureModel  heightFunction;   // gradAlpha | RDF | heightFunction | constant (+ constantCurvature)
```

`constant/phaseChangeProperties` (optional; without it `noPhaseChange` is used). Phase 1 is the liquid:

```
model        HardtWondra;
T_sat        373.15;     // [K]
h_lv         2.26e6;     // [J/kg], phase 1 -> 2
k1           0.68;       // phase-1 conductivity [W/m/K]
k2           0.025;      // phase-2 conductivity [W/m/K]
thetaMin     0.05;       // optional
lambdaCells  1;          // optional, dilatation smoothing length / h
fluxMethod   probe;      // optional: probe | ghostFluid
DilatationSource    true;   // optional switches: PCV in pEqn
PhaseFractionSource true;   //                    alpha1Gen
```

`system/fvSolution`, alpha dictionary:

```
"alpha.water.*"
{
    reconstructionScheme plicRDF;
    plicRDFCoeffs { tol 1e-6; relTol 0.1; iterations 5; interpolateNormal true; }
    nAlphaBounds 3;  snapTol 1e-12;  clip true;
    nAlphaCorr 1;    nAlphaSubCycles 1;
    cAlpha 1;                          // required by interfaceProperties, unused by isoAdvector
    phaseChangeAdvection velocity;     // velocity (default) | source
}
```

Use `ddtSchemes { default Euler; }` and a uniform time step per step (adjustable time step is fine).

## Validation

Run from the case generators in `validation/` (copy to a run directory first; they write into the case).

| Case | Setup | Result |
|---|---|---|
| V34 1D Stefan (`runV34.sh`) | 50 cells, 10 s, water/steam | vapour-layer thickness +4.63 % at t = 10 s vs the analytic solution |
| V6 d²-law droplet (`runV6.sh`) | axisymmetric wedge, R0/h = 8, 2 ms | evaporation constant K −0.08 % vs the mid value of the analytic range; mdot −0.54 % |

The V6 run is short (D² changes by about 6e-4), so it tests the instantaneous evaporation rate rather
than a developed d²-law. The old explicit-source path gave +4.61 % (V34) and −0.50 % (V6) on the same cases.

## Limitations

- `HardtWondra` is the only phase-change model besides `noPhaseChange`; the earlier Stefan/equilibrium
  models were removed.
- Mass transfer uses the converged temperature of the previous time step (one-step lag).
- The velocity form assumes a sharp model whose `mdot'''` sits in interface cells.
- Spurious currents of the CSF force are not eliminated; check them with the static droplet (V1)
  for your resolution.
